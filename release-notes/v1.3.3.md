App Systemizer 1.3.3 · 选中态修复。模块包在本页附件（`App-Systemizer-KSU-v1.3.3.zip`，versionCode 1003003）。

### 修复

- **Material 3**：选中行原来是 8% primary 铺在 surface-highest 上，混出来是一层没有彩度的灰，和禁用态几乎分不出来。改为 `secondary-container` 按 60% 混进卡片底色，文字走 `on-secondary-container`，选中段整体读起来是明确的“已选中”。
- **Miuix**：选中底色原来取 accent-primary 6%，在白色卡片上几乎等于白色，深色下也贴着 `surface-container`，看不出选中。改用 HyperOS 自己的 `tertiary-container`，勾选框仍保留强调色。
- **两套主题共同的问题**：选中行里的徽标底色和新的选中底色同源，铺上色块后会整个消失。MD3 改为 `on-secondary-container` 12% 叠加，Miuix 改为 `surface-container` 底配 `on-tertiary-container` 蓝字。

连续选中的多行仍连成一整块，只在首尾收圆角，行间分隔线隐藏。

### 安装

在 Magisk / KernelSU / SukiSU Ultra 里直接刷入本页附件的 zip，重启生效。WebUI 从模块详情页打开，设置里可以切换 Material 3 与 Miuix 两套主题，两套都跟随系统深浅色。
