App Systemizer 1.4.0 · 界面重做，只保留一套 Material 3。模块包在本页附件（`App-Systemizer-KSU-v1.4.0.zip`，versionCode 1004000）。

### 重做

- **只留 M3**：删掉 Miuix 主题和「UI 风格」切换，颜色角色全部走 `--md-*`：优先读 `--sys-*`（KernelSU/Android 动态取色），没有时回落到 M3 基线色板，深色模式有独立回退。
- **应用页**：状态改成主色卡——36sp 的已托管数量、右下角同心圆、徽章光环和状态胶囊；下面是搜索栏、带图标的分段按钮、计数胶囊和行内复选框列表。保存仍是右下角扩展 FAB，只在有未保存修改时出现。
- **日志页**：新增统计卡（条数、时间范围、OK / 信息 / 警告 / 错误四色图例）和筛选 chip，日志行改成等宽时间 + 状态标签 + 最多两行的命令输出。
- **设置页**：应用信息做成主色卡，下面按「外观 / 日志 / 关于」分组，分组标题带渐隐细线；关于里补了元模块和日志上限。
- **对话框**：确认与重启弹窗换成 28dp 圆角、容器色底、图标光环和右上角同心弧线。

### 新增

- **主题色自定义**：设置 → 外观 → 主题色，可以直接输入六位十六进制色号，或从六个预设里选。`theme.js` 从这颗种子色派生整套 M3 角色（浅色、深色各一套），页面底纹、卡片同心圆、徽章光环都跟着变；「使用系统取色」随时退回动态取色。选择存在 `localStorage` 的 `app-systemizer-theme`。

### 其它

- 字体栈去掉 MiSans，改成 Roboto / Noto Sans SC / 系统字体。
- 挂载、选择、保存、下拉刷新的逻辑未变；日志仍然默认关闭，开启后才出现在底部导航。

### 安装

在 Magisk / KernelSU / SukiSU Ultra 里直接刷入本页附件的 zip，重启生效。WebUI 从模块详情页打开。
